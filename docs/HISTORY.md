# 项目历史（清理版）

本仓库基于 HsAuto 0.9.75 的源码与运行包做了分阶段清理和重构。下面的摘要只
记录公开可说的变更；原始内部审计报告、账号信息、官方二进制和本地路径不在
公开仓库中。

| 阶段 | 内容 |
|---|---|
| Phase 0 | 建立干净的源码树、发布清单和严格门禁；确认 UI/Core/插件可独立构建 |
| Phase 1A | 移除官方自动更新、Updater、PackageInfo 与完整性校验链 |
| Phase 1B | 移除官方 Watchdog 进程，保留 no-op 兼容方法 |
| Phase 1C | 重建游戏插件，移除官方租约、能力校验与遥测改写 |
| Phase 1D-1 | 移除 Frida、AI2/AI3 与相关资源；保留网易盒子策略 |
| Phase 1D-2 | 明确保留并声明网易盒子/HSAng 外部依赖 |
| Phase 1D-3 | 移除网页远控门户与远程业务命令，只保留 GoldStudio 同步 |
| Phase 2A | 移除官方教程、品牌图与官方路径，替换为“酒章”品牌 |
| Phase 2B | 移除卡密/会员页面、授权状态与隐藏 premium 页面 |
| Phase 2C | 移除失效的租约交接；App 接受重建插件的原生登录状态 |
| Phase 2D | 清理剩余卡密处理器、占位与刷新/重登死路径 |
| Phase 2E | 移除本地 `LicenseSession` 占位，改用中性的本地运行会话 |
| D6 | 默认改为 .NET 8 自建单文件发布；官方 apphost 仅用于验证扫描/回退 |
| D10 | 安全清理运行态残留（移至隔离目录，不直接删除账号/Token/设置） |
| D11 | 恢复 AI2.0/2.1 与 AI3.0 策略；鉴权改为 HSAng `user.dat` 的无注入流程，Frida 保持移除 |

核心取舍和外部依赖记录在私有源码树的内部文档中；本公开仓库只保留这份
历史摘要。完整客户端源码和内部审计报告不随本仓库分发。
